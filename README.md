# Weeyzz (MA) artist website

Responsive one-page artist website built with plain HTML, CSS and JavaScript. It has no build step or framework dependency.

## Preview

Open `index.html` in a browser. You can also serve this folder locally with:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Media links

The site includes a Spotify artist embed and profile link, a SoundCloud player using the supplied share link, and YouTube, Instagram and TikTok links. Embedded players depend on the platforms allowing embeds in the visitor's browser.

## Publish free with GitHub Pages

1. Create a GitHub repository and add these project files to its root.
2. Push the files to the repository's `main` branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will show the published address in Pages settings after deployment completes.
